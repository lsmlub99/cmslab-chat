# 지식 문서 템플릿

챗봇이 아직 답하지 못하는 주제를 채우기 위한 빈 양식입니다.

## 왜 이 5개인가

실제 사내 질문 23개로 커버리지를 측정한 결과 15개(65%)만 답변 가능했습니다.
답변하지 못한 8개 질문이 전부 아래 5개 영역에 몰려 있었습니다.

| 파일 | 이 문서가 없어서 못 답한 질문 |
|---|---|
| `01-온보딩.md` | 신규 입사자 온보딩 절차, 입사 시 제출 서류 |
| `02-퇴사절차.md` | 퇴사 절차 |
| `03-재택근무.md` | 재택근무 신청 방법 |
| `04-법인카드-경비정산.md` | 법인카드 사용 규정, 출장비 정산 |
| `05-주차-차량지원.md` | 주차 지원 여부 |
| `06-IT-계정-메일.md` | 회사 메일 휴대폰 연동 |

이 6개를 채우면 커버리지가 65% → 90% 수준으로 올라갑니다.

## 쓰는 법

1. 각 파일을 열어 `(내용을 채워 주세요)` 부분을 실제 사내 규정으로 바꿉니다.
   - 담당 부서에서 자료를 받아 붙여넣으시면 됩니다.
   - **모르는 내용은 비워 두고 지우세요.** 빈칸을 그럴듯한 문장으로 채우면
     챗봇이 그 내용을 사실로 답합니다.
2. 파일 맨 위의 안내 주석(`<!-- -->` 부분)은 지웁니다.
3. 관리자 화면 → **지식 업로드** → 파일 업로드, 또는 본문을 복사해 텍스트로 붙여넣기.
   - 여러 개를 한 번에 넣으려면: `npm run ingest -- knowledge-templates`

## 잘 찾히게 쓰는 요령

챗봇은 질문 문장과 문서 내용의 의미가 가까울수록 잘 찾습니다.

- **직원이 쓰는 말로 쓰세요.** "재택근무 신청"이라고 물어볼 텐데 문서에 "원격근무제
  운영지침"이라고만 적혀 있으면 잘 안 걸립니다. 둘 다 적어 두면 됩니다.
- **질문-답변(Q&A) 형태가 특히 잘 맞습니다.** 기존 `인사행정_Q&A` 문서가
  검색 성적이 가장 좋습니다.
- **한 문서에 한 주제.** 여러 주제를 한 파일에 몰아넣으면 엉뚱한 문단이 근거로 붙습니다.
- **숫자와 절차를 구체적으로.** "적정 금액 지원"보다 "1인 3만원 한도"가 훨씬 쓸모 있습니다.
- 링크가 있으면 그대로 적어 두세요. 챗봇이 답변에 링크를 안내합니다.
